## 🎯 Quick Navigation Guide

### Want to edit public website?
```
📁 src/pages/          → Add/edit public pages
📁 src/components/     → Add/edit public components
📁 src/data/           → Update trek/tour data
```

### Want to edit admin panel?
```
📁 src/backend/        → Add/edit admin pages
📁 src/data/           → Update admin data storage
📁 src/hooks/          → Add/edit admin hooks
```

### Want to edit API?
```
📁 backend/src/routes/      → Add/edit API routes
📁 backend/src/controllers/ → Add/edit API logic
📁 backend/src/services/    → Add/edit services
```

### Want to configure deployment?
```
📄 render.yaml              → Render deployment config
📄 vite.config.js           → Frontend build config
📄 vite.config.admin.js     → Admin build config
📄 .env.example             → Environment variables
```

## 🔐 Security Boundaries

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  🌐 PUBLIC ZONE (www.gadvede.com)                           │
│  ├── No authentication required                            │
│  ├── Read-only access to products                          │
│  ├── Can submit bookings/enquiries                         │
│  └── No admin features exposed                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  🔒 PROTECTED ZONE (admin.gadvede.com)                      │
│  ├── Authentication required                               │
│  ├── JWT token validation                                  │
│  ├── Admin API key required                                │
│  ├── Full CRUD operations                                  │
│  └── Admin panel access                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

This structure ensures clean separation and security! 🚀
